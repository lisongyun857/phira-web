服务端配置

只读展示当前运行配置，敏感项仅显示是否已配置。

以下修改会写入服务端 runtime-config.json，重启后仍然生效。

修改管理员密码

修改成功后当前会话保持有效，其他管理员会话会被注销。

密码长度 6~64 位，修改后请使用新密码登录。

修改 access_token

用于 QQ 插件和旧的令牌认证方式。

配置 access_token 后，QQ 插件必须在其配置里填写同样的 api_token，否则管理类指令会返回 401。

留空并保存表示清除 access_token。

允许来源 allowed_origins

每行一个来源，例如 https://phira.example.com 或 *。

至少保留一个来源，可使用 * 允许所有来源。

API 地址设置

填写后端 HTTP API 的根地址，不要带末尾斜杠。地址保存在当前浏览器中。
